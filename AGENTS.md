# Project rules

## Canonical term: prep list

Use **prep list** as the only canonical term for the kitchen preparation list.

When a user writes `preplist`, `preplis`, `prepli`, `playlist`, or another obvious spelling variant while referring to this kitchen feature, interpret it as **prep list** and continue without asking for a terminology correction.

Keep the canonical term in source code, routes, API names, database names, UI labels, tests, and documentation. Use `prep` for the established technical shorthand (`/prep`, `usePrep`, `prep_state`). Treat `playlist` as a music term only when the surrounding request clearly refers to music.

If a new request appears to introduce a different kitchen concept, resolve that meaning before creating a second term.
